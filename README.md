# NEX-LAUNCHER
A launcher that plans to connect with steamworks api

> **Note:** Nex Launcher is designed to be an ecosystem ally. **We do not compete with Steam** we enhance local performance, streamline game launching, and respect the core Steam infrastructure.

---

## The Vision & Roadmap

Nex Launcher is being built in structured phases, with a clear focus on official alignment:

1. **Phase 1: MVP & Architecture** 
   - Build a lightweight, resource-efficient client wrapper that interfaces cleanly with local Steam paths and URI schemes.
   - Maintain strict public transparency while protecting proprietary codebase rights.

2. **Phase 2: Independent Testing & Validation**
   - Soft-launch with indie titles and custom developer projects to prove stability, speed, and reliability.
   - Demonstrate a sustainable economic model that benefits players and creators alike.

3. **Phase 3: Valve Partnership & Integration**
   - Present the fully functioning MVP to Valve's partner relations.
   - Secure official Steamworks API integration and partnership agreements to guarantee secure, compliant revenue sharing and infrastructure alignment.
